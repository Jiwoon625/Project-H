# Project-H · 아파트 임장 후보 대시보드

서울 25개 구와 안양시의 3,641개 단지를 입지와 가격으로 비교합니다. [대시보드 열기](https://jiwoon625.github.io/Project-H/)

## 평가기준

- **가격**. 59㎡와 84㎡ 각각 최근 3개월 단지 중위가격을 사용합니다. 본인을 제외한 같은 주택유형·준공 ±5년·반경 2km 내 단지를 비교합니다. 같은 동에서 3개 이상이면 그 표본을 쓰고, 부족하면 같은 구까지 넓히며, 같은 구에서도 3곳을 채우지 못한 단지는 반경 2km 안의 인접 구·시 단지까지 함께 비교해 화면에 **인접 구 포함(참고)** 로 표시합니다. 비교군 중위가격은 단지당 동일 가중입니다. 비교군이 3곳 미만인 경우 차이를 계산하지 않습니다. 상대가격 = (해당 단지 중위가격 ÷ 비교단지 중위가격 − 1) × 100. 생활권은 도로·학군 경계의 차이를 모두 포착하지 못하므로 비교단지 명단도 제공합니다.
- **첫 화면**. 처음에는 서울 단지만 그립니다(단지가 4천 개를 넘어 초기 렌더링 비용이 커졌기 때문). 지역 선택에서 경기나 전체 지역을 고르면 수집한 경기 시·구가 함께 표시됩니다. 차트에서 단지를 클릭하면 상세가 고정되어 마우스를 지나가게 해도 바뀌지 않고, 빈 곳을 더블클릭하거나 '선택 해제'를 누르면 풀립니다.
- **가격 신뢰도**. 해당 면적형 거래가 1건이면 낮음, 3건 이상이고 비교단지 5곳·비교거래 10건 이상이면 높음, 나머지는 보통입니다. 등급은 표본 충족 여부를 나타냅니다. 최근 계약월은 서울 거래 원장의 단지명·구·동·준공연도·면적형·건수·중위가격이 일치한 경우에만 표시합니다. 안양과 미대조 단지에는 확인된 집계기간을 표시합니다.
- **임장 후보**. 입지 60점 이상이면서 비교군보다 10% 이상 저렴한 곳을 신뢰도, 가격 차이 순으로 보여줍니다. 절대가격 보기에는 기존 수도권·전국 가격 기준을 유지했습니다. 시세 열에 과거 분기 가격을 이월하는 경우 경과 분기를 표시합니다.
- **입지 100점**. 대표 목적지 6곳 중 가까운 두 곳의 평균 출근시간(20분 이하 24점, 85분 이상 0점, 사이 선형)과 45분 내 목적지 비율(12점), 기존 역 접근성(14점), 배정 초교 보행거리(300m 이하 18점, 1,800m 이상 0점, 사이 선형), 중·고교 수(4점), 기존 마트·의료 접근성(28점)을 합산합니다. 출근 경로가 2곳 미만이거나 배정 초교 경로가 불완전하면 총점을 보류합니다. 배점은 임장 선별을 위한 초기 설정입니다.
- **상품성·환금성**. 기존 세대수·연식·설비 15점을 상품성 100점으로, 회전율·전세가율 15점을 환금성 100점으로 각각 환산합니다. 두 점수는 입지와 별개입니다. 과거 산포도는 기존 종합점수 전용 화면에서 볼 수 있고, 준공 전 관측은 제외합니다.
- **통근·통학**. 오전 9시까지 도착하는 시간표 경로를 역산합니다. 출발 단지 대표점·목적지에서 900m 이내 정류장을 탐색하고 도보 우회계수 1.3, 보행속도 초속 1.2m, 최초 승차 여유 2분, 환승 여유 3분 및 250m 이내 환승 도보를 적용합니다. 2km 이내는 직접 도보와도 비교합니다. 직장 수·혼잡도 대신 6개 대표 목적지별 예상시간을 제공합니다. 초등 통학구역 경계와 단지 대표점을 교차해 공동통학구역의 복수 학교까지 표시합니다. 보행망에서 후보 출입구를 찾은 경우 출입구를, 나머지는 대표점을 사용합니다. 최대 120m 접속·6km 탐색으로 경로를 추정합니다. 공동통학구역은 가장 긴 통학거리로 평가합니다. 지도에 등록된 주요도로 횡단 지점·계단·경사 정보는 참고항목입니다.

## 데이터와 재생성

기본 자료는 국토교통부 RTMS 매매·전월세, K-apt, 카카오 로컬로 구축한 기존 `data.json`입니다. 2026년 9~11월 가격 관측은 11월 27일 00:39 KST 스냅샷입니다. 11월 계약은 추가 신고될 수 있습니다.

| 입력 파일 | 출처·기준 |
|---|---|
| `gtfs.zip` | [Transitous 한국 피드 목록의 KTDB 전국 GTFS](https://github.com/public-transport/transitous/blob/main/feeds/kr.json). 사용한 ZIP 내부 시간표 파일 작성일 2025-05-21. 평일 06~09시 버스·도시철도 운행을 사용합니다. |
| `zones`, `schools`, `links` | [한국교육시설안전원 공공데이터](https://schoolzone.emac.kr/publicData/publicDataList.do). 2026-09-20 배포분의 초등통학구역, 학교 위치, 학교–학구 연계 ZIP. 학교 좌표 CSV 기준일은 2026-10-01입니다. |
| `roads.osm.pbf` | [Geofabrik 대한민국](https://download.geofabrik.de/asia/south-korea.html) 2026-11-26 추출본. © [OpenStreetMap contributors, ODbL](https://www.openstreetmap.org/copyright). |
| `sales.db` | [서울 실거래 리포트 공개 원장](https://github.com/silgeorae-report/silgeorae-report.github.io/blob/main/data/pipeline.db). 국토교통부 서울 매매자료 중 해제되지 않은 거래로 최근 계약월을 대조합니다. |

배포용 HTML은 `python tools/build.py`로 생성합니다. Plotly는 CDN에서 읽으며, 단지·가격·경로 데이터는 HTML에 내장됩니다. 원자료를 갱신할 때는 위 파일을 한 디렉터리에 넣고 저장소 루트에서 다음을 실행합니다.

```sh
python -m pip install numpy scipy pyshp pyproj shapely osmium
python tools/commute.py inputs/gtfs.zip inputs/commute.json
python tools/school_routes.py inputs inputs/routes.json
python tools/access.py inputs
python tools/build.py
```

추가 지표는 단지코드와 좌표로 결합합니다. 거래월은 스냅샷 시각이 일치할 때만 노출됩니다. 기존 데이터 수집기는 별도 작업 경로의 `work-apt/seoul/pipeline.py`입니다.
