# 아파트 입지 × 시세 9분면 대시보드

서울 15개 구 + 경기 안양시 아파트를 **입지 100점(X축)** 과 **전용 59~85.5㎡ 최근 3개월 중위 평당가(Y축)** 로 배치한 인터랙티브 대시보드입니다.

- `index.html` — 데이터가 내장된 단일 파일(Plotly CDN). 열기만 하면 동작합니다.
- `data.json` — 단지 2,679개 · 11개 시점 궤적(2016~2026) 원본 데이터
- `index_template.html` — 빌드 템플릿 (`work-apt/dashboard/build_data.py`가 `/*__DATA__*/` 자리에 데이터를 주입)

## 화면 기능
- **컷 프리셋**: 수도권(X 30/60점 · 평당 2,000/3,500만) ↔ 전국(X 30/60점 · 평당 1,500/3,000만)
- **기간 슬라이더(1~10년)**: 선택한 기간만큼 과거 시점 → 2026년 궤적 표시
- **점 클릭/호버**: 해당 단지 궤적 강조 + 세대수·준공·최근접역 거리·입지점수·평당가·전세가율·축별 점수·연도별 표
- **지역(시/구) 필터 · 단지명 검색 · '입지 상 & 시세 하' 퀵 필터**

## 데이터 출처
- 국토교통부 실거래가 공개시스템(RTMS) 매매·전월세 2016~2026
- K-apt 공동주택 단지정보(세대수·준공연도·난방·관리방식 등)
- 카카오 로컬 API(지하철·초등학교·대형마트·병원·학원 등 1.5km 반경)

API 키·개인정보는 포함하지 않습니다. 수집·점수화 코드는 `work-apt/seoul/pipeline.py`, 대시보드 빌더는 `work-apt/dashboard/build_data.py` 입니다.
